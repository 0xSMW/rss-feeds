Feeds RSS automatizados para blogs de investigación de IA que no los proporcionan de forma nativa.

Cada feed incluye el contenido completo del artículo (no solo los títulos), para que puedas leer todo directamente en tu lector de RSS. Los feeds se actualizan automáticamente a través de GitHub Actions e incluyen el formato, imágenes y enlaces adecuados.

Perfecto para mantenerse al día con la investigación de IA sin tener que revisar múltiples sitios manualmente.

Idea derivada de [https://github.com/Olshansk/rss-feeds/](https://github.com/Olshansk/rss-feeds/)
